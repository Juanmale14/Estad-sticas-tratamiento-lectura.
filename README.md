📊 Analizador de Comprensión Lectora

Herramienta web profesional diseñada para la gestión académica y el análisis estadístico de resultados de comprensión lectora en centros educativos (1º a 4º de ESO).

Esta aplicación permite a los equipos directivos y docentes transformar datos brutos de Excel en informes visuales detallados y documentos PDF listos para impresión o archivo.

🚀 Funcionalidades Principales

Procesamiento de Datos: Carga de archivos Excel (.xlsx) con desglose por grupos.

Estadísticas Globales: Cálculo automático del total de alumnado evaluado y distribución por niveles competenciales (Óptimo, Medio, Inadecuado).

Análisis por Niveles: Consolidación automática de datos según el nivel educativo (1º de ESO, 2º de ESO, etc.).

Visualización Dinámica: Gráfico de barras apiladas interactivo para comparar el rendimiento entre diferentes grupos.

Plan de Acción Automático: Generación de conclusiones pedagógicas basadas en los datos analizados.

Exportación Profesional: Generación de informes en PDF optimizados para formato A4 con portada personalizada.

📋 Requisitos de los Datos (Excel)

Para que el análisis sea preciso, el archivo de Excel debe tener el siguiente formato de columnas:

🛠️ Tecnologías Utilizadas

Tailwind CSS: Para un diseño moderno, responsivo y profesional.

Chart.js: Renderizado de gráficos estadísticos de alta calidad.

SheetJS (XLSX): Procesamiento de archivos Excel directamente en el navegador.

html2pdf.js: Motor de generación de documentos PDF desde el DOM.

Plus Jakarta Sans: Tipografía premium para mejorar la legibilidad académica.

📂 Instalación y Uso

La aplicación es Serverless (sin servidor), lo que significa que funciona completamente en el cliente. No requiere base de datos ni instalación compleja.

Clona este repositorio o descarga el archivo analisis_comprension_lector.html.

Abre el archivo en cualquier navegador moderno (Chrome, Firefox, Edge).

Sube tu archivo de datos en la pestaña "Datos" o haz clic en "Cargar Datos de Ejemplo" para ver una demostración.

Navega a la pestaña "Análisis" para revisar las estadísticas.

Exporta el resultado final en la pestaña "Exportar".
